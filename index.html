Признание на моём языке

Я не всегда умею говорить красиво. Зато умею писать код, который никогда не останавливается. Нажми «Запустить» — это настоящий цикл.

love_for_mom.js
// работает без перебоев с самого моего рождения
const сердце = new Любовь({
  адресат: 'мама',
  срок: Infinity
});

while (true) {
  сердце.обнять();
  сердце.сказать('спасибо за всё');
  if (мама.улыбается()) {
    мир.становится('лучше');
  }
}
// цикл не прерывается. так и задумано ♥
