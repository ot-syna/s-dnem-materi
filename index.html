Три способа получить ссылку за пару минут

Файл index.html сам по себе ссылкой не станет: его нужно положить в интернет. Любой из вариантов бесплатный и работает с одним файлом.

самый быстрый

Netlify Drop

  1. Открой app.netlify.com/drop
  2. Перетащи папку с файлом index.html прямо в окно браузера
  3. Через 10 секунд получишь адрес вида имя.netlify.app — вставь его сюда
Открыть Drop
по-программистски

GitHub Pages

  1. Создай репозиторий, например mama-gift, и загрузи index.html
  2. Settings → Pages → Source: Deploy from a branch, ветка main, папка /root
  3. Ссылка появится вида ник.github.io/mama-gift
git init git add index.html git commit -m "подарок маме" git branch -M main git remote add origin https://github.com/USER/mama-gift.git git push -u origin main

главный вопрос

В каком формате отправлять ссылку

Ссылка везде одинаковая — разный носитель. В мессенджере это текст с карточкой-превью, в SMS — просто короткий адрес, на бумаге — QR-код, а без интернета — сам файл. Выбери канал: сообщение и способ отправки перестроятся под него.

Рекомендация прямо сейчас

Добавь адрес подарка — и я подскажу точный формат.

шаг 2 · текст и канал

Сообщение, которое придёт маме

Слева — текст и канал, справа — ровно то, что она увидит на экране телефона. Превью-карточка в пузырьке собирается из твоей обложки и заголовка.

шаг 3 · превью ссылки

Обложка, которая раскроется в чате

Telegram, WhatsApp и VK показывают ссылку карточкой: картинка 1200×630, заголовок, описание. Без неё сообщение выглядит как голая строка. Собери обложку, скачай og-cover.png и вставь мета-теги в подарок — карточка появится автоматически.

    шаг 5 · без интернета
    
Отправить самим файлом или открыткой

    
Если публиковать сайт некуда — подарок можно передать как документ. Файл .html открывается в любом браузере и работает офлайн: музыка, букет и обнимашки внутри него самого.


    

      

        
        

          
          
podarok.html0 КБ

          
        

        

          
          
        

        

          Как отправлять файлом: в Telegram и WhatsApp — скрепка → Файл / Документ (не «Фото»), выбрать podarok-dlya-mamy.html. Мама нажимает на файл → «Открыть в браузере». В почте — обычным вложением. Ссылка при этом не нужна вообще.
        

        

          Что выбрать в итоге: есть публичный адрес → отправляй текст + ссылку в мессенджер (с обложкой это выглядит как настоящая открытка). Адреса нет → отправляй файл. Встречаетесь лично → распечатай QR-открытку.
        

      


      

        

        

          
          
        

        
Открытка-конверт — самостоятельный файл: письмо, QR-код и большая кнопка «Открыть подарок». Её можно отправить вместо длинного сообщения или распечатать и вложить в настоящий конверт.
